# 源码树对照：四套 Emuera 实现

本仓库中存在四份 Emuera 相关的实现/构建产物，写 ERB 或读本套文档时容易混淆。
本文记录它们的身份、版本谱系与命令集差异。

## 一、身份总表

| 位置 | 版本标识 | 目录布局 | 角色 |
|---|---|---|---|
| `emuera.em/Emuera/` | `1.824+v24+EMv18+EEv56`（`Emuera.csproj` 的 `InformationalVersion`） | 重构版：`Runtime/`、`UI/` | **本套文档的权威依据**（`test/data/commands`、`functions`、`language` 全部据它撰写） |
| `eraTW/Emuera1824+v18+EMv17+EEv41.exe` | `1.824+v18+EMv17+EEv41` | —（二进制） | **eraTW 实际运行的运行时**，随游戏分发 |
| `eraTW/パッチ/Emuera1824+v11+webp+test+fix/src1824+v11+webp+test+fix/Emuera/` | `1.824.0.11` | 经典版：`GameData/`、`GameProc/`、`GameView/` | eraTW 补丁目录内附的**私家改造版 v11 源码基线**（含 webp / test+Fix 补丁） |
| `Emuera/`（仓库根） | `1.824.*` | 经典版，同上的目录结构 | 本家系与私家改造版系的经典布局源码树（比 v11 基线新，含 `ErbArchiveLoader`/`IErbLoader` 的 ERB 归档功能） |

## 二、版本谱系

```
Emuera 1.824（本家）
   └─ 私家改造版 v1 … v18（只做 bug 修复，不加功能：见「私家改造版Emuera_readme.txt」的方针）
        └─ EM（Emuera私家版）v17 / EE（EmueraEE 扩展）v41  →  eraTW 随附 exe
        └─ EM v18 / EE v56                                  →  emuera.em/（本套文档依据，重构布局）
```

- `私家改造版` 的定位是「Emuera 本家停止维护后的 bug 修复基线」，明确声明不做功能变更；
  其修复历史（v1～v11）逐条记录在
  `eraTW/パッチ/Emuera1824+v11+webp+test+fix/私家改造版Emuera_readme.txt`。
- `emuera.em`（EMv18/EEv56）是这条线的后续世代，**继承了上述全部修复并叠加 EM/EE 扩展**。
  已抽验确认修复在 `emuera.em` 中存在：

  | 修复项（私家改造版 changelog） | `emuera.em` 中的证据 |
  |---|---|
  | v10：VARSET 特定条件下不工作 | `Runtime/Script/Statements/Instraction.Child.cs:1672` 起，含原注释 `//endを先に取って判定の処理変更` 与 `start > end` 交换 |
  | v9：ARRAYMSORT 从 Int32 扩到 Int64 | `ArrayMultiSortMethod` 用 `long[]`（`Function/Creator.Method.cs:4068`） |
  | v6 / v6.1：UNICODE 拒收控制字符（LF/CR 除外），改为警告 + 返回空串 | `Function/Creator.Method.cs:4694`「改行関係以外の制御文字は警告扱いに変更」 |
  | 1821+v11：历史显示行数固定为 10000 | 配置项 `MaxLog`（`Runtime/Config/ConfigData.cs:63`，默认 5000） |
  | 1821+v11.1：REPEAT/FOR 嵌套由错误降为警告 | 装载期 `ErbLoader` 只报警告级 1 |
  | 1823+v1：TOOLTIP_SETDELAY 与 SETDURATION 併用失效 | 两者均在本树实现（`Instraction.Child.cs:2136` 起） |

## 三、命令集差异

以 `BuiltInFunctionCode.cs` 的枚举成员比对：

| 比对 | 结果 |
|---|---|
| `eraTW/パッチ` v11 树 vs 仓库根 `Emuera/` | 命令枚举**完全一致**（各 266 条）；两树仅 28 个文件有差异（根源码新增 ERB 归档等） |
| `emuera.em` vs 上述两棵经典树 | `emuera.em` 多 39 条，经典树多 1 条 |

- **经典树独有 1 条**：`OUTPUTLOG`。在 `emuera.em` 中该命令形式被注释停用，改以**式中函数** `OUTPUTLOG(文件名{, hideInfo})` 提供（见 `commands/OUTPUTLOG.md`）。
- **`emuera.em` 独有 39 条**：EM/EE 扩展，即 `BINPUT`、`BINPUTS`、`BREAKBUTTON`、`CALLSHARP`、
  `CLEARBGIMAGE`、`DT_COLUMN_OPTIONS`、`FORCE_BEGIN`、`FORCE_QUIT`、`FORCE_QUIT_AND_RESTART`、
  `HTML_PRINT_ISLAND`、`HTML_PRINT_ISLAND_CLEAR`、`INPUTANY`、`ONEBINPUT`、`ONEBINPUTS`、
  `PLAYBGM`、`PLAYSOUND`、`PRINTN`/`PRINTVN`/`PRINTSN`/`PRINTFORMN`/`PRINTFORMSN`、
  `QUIT_AND_RESTART`、`REMOVEBGIMAGE`、`SETBGIMAGE`、`SETBGMVOLUME`、`SETSOUNDVOLUME`、`SKIPLOG`、
  `STOPBGM`、`STOPSOUND`、`TOOLTIP_CUSTOM`/`TOOLTIP_FORMAT`/`TOOLTIP_IMG`/`TOOLTIP_SETFONT`/`TOOLTIP_SETFONTSIZE`、
  `TRYCALLF`、`TRYCALLFORMF`、`UPDATECHECK`、`VARI`、`VARS`。

### 文档树 vs eraTW 运行时（EMv18/EEv56 vs EMv17/EEv41）

在 eraTW 随附的 exe 中检索上述 39 个名字，**24 个存在、15 个不存在**：

| 在 eraTW exe 中可用（24） | 在 eraTW exe 中**不可用**（15） |
|---|---|
| `BINPUT`、`BINPUTS`、`DT_COLUMN_OPTIONS`、`FORCE_BEGIN`、`FORCE_QUIT`、`FORCE_QUIT_AND_RESTART`、`INPUTANY`、`PLAYBGM`、`PLAYSOUND`、`QUIT_AND_RESTART`、`SETBGMVOLUME`、`SETSOUNDVOLUME`、`SKIPLOG`、`STOPBGM`、`STOPSOUND`、`TOOLTIP_CUSTOM`、`TOOLTIP_FORMAT`、`TOOLTIP_IMG`、`TOOLTIP_SETFONT`、`TOOLTIP_SETFONTSIZE`、`TRYCALLF`、`TRYCALLFORMF`、`UPDATECHECK`、`VARS` | `BREAKBUTTON`、`CALLSHARP`、`CLEARBGIMAGE`、`HTML_PRINT_ISLAND`、`HTML_PRINT_ISLAND_CLEAR`、`ONEBINPUT`、`ONEBINPUTS`、`PRINTN`、`PRINTVN`、`PRINTSN`、`PRINTFORMN`、`PRINTFORMSN`、`REMOVEBGIMAGE`、`SETBGIMAGE`、`VARI` |

**实践含义**：本套文档按 `emuera.em`（EMv18/EEv56）撰写，描述的语义与最新世代一致。
若要写**在 eraTW 随附 exe 上运行**的 ERB，上表右列的 15 个命令不可用——
尤其是 `PRINTN` 族（本套文档 `commands/PRINT.md` 记载其语义为「不换行 + 等待回车」）与 `SETBGIMAGE` 系。
反之，左列的 24 个可以放心使用。

`COLUMNCREATE` 等 `COLUMN*` 命令在两者中都不是原生命令（EE 发行版以 ERB 库形式提供，见 `commands/COLUMNCREATE.md`）。

## 四、写 ERB 时的选择建议

| 目标 | 用哪棵树的行为为准 |
|---|---|
| 跟随最新 Emuera（本套文档的语义） | `emuera.em/Emuera`（EMv18/EEv56） |
| 在 eraTW 随附 exe 上运行 | 相同，但避开上文右列 15 个命令 |
| 需要「只修 bug、不加功能」的最小基线 | `eraTW/パッチ/…/src1824+v11+…`（v11 树）或仓库根 `Emuera/` |
