# 语句与复合语句

> 来源：ecd/docs/ERB_Statements（ERB 的语句）、ecd/docs/ERB_Compound_Statements（ERB 的复合语句）；zh 套件 ERB_File_Format（教程中的 SIF/IF/REPEAT 节）交叉核对；源码 `Runtime/Script/Loader/ErbLoader.cs`、`Runtime/Script/Statements/Instraction.Child.cs`、`Runtime/Script/Process.ScriptProc.cs`。

## 概述

EraBasic 遵循「一行一句」：除函数定义（`@`）、标签（`$`）、预处理（`#`）、注释（`;`）与预处理区块行（`[XXX]`）外，每个物理行就是一条语句。语句分两类——**简单语句**（赋值、命令、SIF、跳转）与**复合语句**（跨多行的 IF/FOR/WHILE/SELECTCASE/PRINTDATA 等块结构）。复合语句在装载期由 `ErbLoader.nestCheck` 用栈做配对检查，在运行期由各指令类的 `JumpTo` 双向跳转实现。

## 简单语句

### 语句的种类

| 种类 | 说明 | 例子 |
| --- | --- | --- |
| 赋值语句 | 把右值装进左值 | `A = 10`、`A += 1`、`S '= "文本"` |
| 命令语句 | 调用引擎内置命令 | `PRINTL Hello`、`WAIT` |
| 跳转语句 | 改变执行位置 | `GOTO`、`CALL`、`JUMP`、`RETURN`、`BEGIN` |
| 单行条件语句 | 条件成立才执行下一行 | `SIF A > 0` |
| 循环控制 | 跳出/继续当前循环 | `BREAK`、`CONTINUE` |
| 注释 | 不执行 | `; 说明` |

赋值与命令的逐条语义不在本篇展开（详见 test/data/commands/ 各文件），本篇关注**语句层的结构性规则**。

### 赋值语句

```erb
A = 10
S = "文本"
A = A + 1        ; 先算右边，再存回左边
CFLAG:0:5 = 100  ; 数组元素
A += 1  A -= 1  A *= 2  A /= 2  A %= 2   ; 复合赋值
S '= "文本" + TOSTR(A)                    ; 字符串赋值用 '=
```

- 左右类型必须一致：数值变量只装数值，字符串变量只装字符串；
- `zh/ERB_File_Format`（Eramaker 篇）要求 `=` 两侧留空白、禁止小数——Eramaker 的规则；Emuera 中 `MONEY=500` 也能解析，且表达式整体支持小数（`TIMES` 等，见 test/data/commands/）。

### 命令语句

命令名与参数间以空白分隔，参数格式由命令决定。非调试模式下，调试系命令（`DEBUGPRINT` 等）按「什么也不做」处理——`runScriptProc` 直接 `continue`（`Runtime/Script/Process.ScriptProc.cs:36-39`）。`SKIPDISP 1` 期间所有 PRINT 系命令被跳过（`Runtime/Script/Process.ScriptProc.cs:46-55`）。

### 单行条件语句 SIF

`SIF 条件` 只控制**下一行**是否执行，等价于单句 IF。源码要点（`Runtime/Script/Statements/Instraction.Child.cs:3145-3185`）：

```text
// Instraction.Child.cs:3153-3184（伪代码）
SIF.SetJumpTo:                              // 装载期第三轮调用
    next = func.NextLine
    if next 为空 / 是函数定义行(@) / NullLine:
        警告 NothingAfterSif（级别 2，错误）      // SIF 后没有可执行行
    elif next 是复合语句开头（IsPartial）:
        警告 FuncCanNotAfterSif                // SIF 的下一行不能是 IF/FOR 等
    elif next 是 $ 标签:
        警告 LabelCanNotAfterSif               // SIF 的下一行不能是标签
    else: func.JumpTo = 下一行的下一行          // 条件为假时跳到这里
SIF.DoInstruction:                          // 运行期
    if 条件 == 0: state.ShiftNextLine()        // 假：跳过下一行
    // 真：什么都不做，顺序流入下一行
```

因此文档中「`SIF` 的下一行不能是空行、注释行或标签行」的完整规则是：下一行必须是**普通简单语句**；空行/注释虽被跳过仍可运行，但会触发 `EmptyAfterSif` 警告（`Runtime/Script/Statements/Instraction.Child.cs:3175-3176`，按行号连续性检查）；`@` 函数行、`IF`/`REPEAT` 等复合块开头则直接报错。

### 跳转语句（结构层）

- `GOTO 标签`：跳到同函数内的 `$` 标签；`TRYCGOTO` 前缀变体允许目标不存在；
- `CALL`/`JUMP`（含 `CALLFORM`/`JUMPFORM`）：跨函数调用/跳转，调用模型详见 language/ERB结构与函数.md；
- `RETURN`：结束当前函数并回写 `RESULT`/`RESULTS`；
- `RESTART`：跳回当前函数开头（`JumpTo(func.ParentLabelLine)`，`Runtime/Script/Statements/Instraction.Child.cs:3435-3437`）；
- `BEGIN`：切换系统流程，终结当前函数链（`Runtime/Script/Statements/Instraction.Child.cs:3044-3053`，EE 版 `FORCE_BEGIN` 忽略 `__CAN_BEGIN__` 检查）。

## 复合语句

复合语句跨多行、控制分支或循环，全部**成对出现**。装载期第三轮解析对每个函数做三次处理（`ErbLoader.ParseFunctionWithCatch`，`Runtime/Script/Loader/ErbLoader.cs:881-903`）：`setArgument`（参数预解析）→ `nestCheck`（块配对）→ `setJumpTo`（跳转目标）。

### 配对与嵌套检查（nestCheck）

`nestCheck` 逐行扫描函数体，用 `nestStack` 维护未闭合的块，并做内容合法性检查（`Runtime/Script/Loader/ErbLoader.cs:934-1480`）：

```text
// ErbLoader.cs:934-1480（伪代码，节选）
nestCheck(label):
    nestStack: Stack; SelectcaseStack: Stack
    foreach line in 函数体:
        baseFunc = nestStack.Peek()
        if baseFunc 是 PRINTDATA 系 / STRDATA:
            只允许 DATA / DATAFORM / DATALIST / ENDLIST / ENDDATA   // :983-991
        elif baseFunc 是 DATALIST: 只允许 DATA / DATAFORM / ENDLIST // :992-999
        elif baseFunc 是 TRYCALLLIST / TRYJUMPLIST / TRYGOTOLIST:
            只允许 FUNC / ENDFUNC                                   // :1000-1007
        elif baseFunc 是 SELECTCASE 且 CASE 列表为空:
            只允许 CASE / CASEELSE / ENDSELECT                      // :1008-1015
        switch line.FunctionCode:
            REPEAT → 若栈中已有 REPEAT 警告 NestedRepeat（1 级，仅警告）  // :1019-1038
                      若嵌在外层 FOR 里且 FOR 计数变量是 COUNT:0 警告 RepeatInsideFor
            IF     → 压栈；建立 IfCaseList                            // :1039-1043
            SELECTCASE → 压栈（两个栈都压）                            // :1044-1048
            FOR    → 计数变量为 COUNT 的重名检查后压栈                  // :1049-1080
            WHILE / DO / TRYC 系 → 压栈                                // :1081-1090
            BREAK / CONTINUE → 向栈底找最近的 REPEAT/FOR/WHILE/DO，
                               找不到报 InvalidLoopInstruction（2 级）   // :1091-1111
            ELSEIF / ELSE → 栈顶必须是 IF，追加进 IfCaseList；
                            ELSE 之后再来 ELSEIF/ELSE 警告 InvalidElseAfterElse // :1113-1127
            ENDIF → 栈顶必须是 IF；给 IF 与全部 ELSEIF 的 JumpTo 指向 ENDIF，弹栈 // :1128-1142
            CASE / CASEELSE → 栈顶必须是 SELECTCASE；CASEELSE 后再来 CASE 警告 // :1143-1169
            ENDSELECT → 弹栈；ENDSELECT 及全部 CASE 的 JumpTo 指向 ENDSELECT；
                         每个 CASE 的字面量类型必须与 SELECTCASE 表达式一致      // :1170-1224
            REND / NEXT / WEND / LOOP → 栈顶必须是对应的
                         REPEAT / FOR / WHILE / DO，双向记录 JumpTo，弹栈        // :1225-1241
            CATCH → 栈顶必须是 TRYC 系，TRYC 记住 CATCH 位置，CATCH 压栈      // :1242-1258
            ENDCATCH → 栈顶必须是 CATCH                                       // :1259-1268
            PRINTDATA 系 / STRDATA → 禁止相互嵌套，压栈                        // :1269-1318
            DATALIST / ENDLIST / DATA / DATAFORM / ENDDATA → 按所属块校验      // :1319-1379
            TRYCALLLIST 系 / FUNC / ENDFUNC → FUNC 必须在 LIST 块内            // :1380-1437
            NOSKIP / ENDNOSKIP → 配对                                          // :1438-1463
    扫描结束时 nestStack 非空 → 逐个报告 MissingCorresponding（缺少闭合）       // :1468-1477
```

由此得到的嵌套规则比文档更精确：

- **任意嵌套是允许的**，但 PRINTDATA 系与 STRDATA 之间禁止互相嵌套（`NestedPrintdata`/`StrdataInsidePrintdata` 等），TRYCALLLIST 系禁止嵌套自身，NOSKIP 禁止嵌套；
- **REPEAT 嵌套 REPEAT 只是 1 级警告**（eramaker 不支持嵌套，Emuera 放行为警告；实际共享 `COUNT` 导致逻辑混乱）；
- `FOR COUNT, ...` 嵌在 REPEAT 内或 FOR 的计数变量同用 `COUNT` 时会警告 `RepeatInsideFor`（`Runtime/Script/Loader/ErbLoader.cs:1020-1075`）；
- `BREAK`/`CONTINUE` 出现在任何循环外是 2 级错误 `InvalidLoopInstruction`；
- 漏写 `ENDIF`/`REND`/`NEXT`/`WEND`/`LOOP`/`ENDSELECT`/`ENDCATCH`/`ENDDATA`/`ENDFUNC`/`ENDNOSKIP` 在函数扫描结束时统一报 `MissingCorresponding`。

### IF / ELSEIF / ELSE / ENDIF

```erb
IF 条件
    ; 条件成立时执行
ELSEIF 另一条件      ; 可有多个，也可没有
    ; …
ELSE                 ; 可没有
    ; …
ENDIF                ; 必须有
```

运行期 `IF_Instruction` 按顺序求值 `IfCaseList`（IF 本体、各 ELSEIF），命中即跳到该分支行；全不成立跳到 `ELSE`（若有）或 `ENDIF`（`Runtime/Script/Statements/Instraction.Child.cs:3216-3268`）。条件以 `0` 为假、非 0 为真。ELSEIF/ELSE 本身执行时只是无条件跳到 ENDIF（`Runtime/Script/Statements/Instraction.Child.cs:3187-3203`），保证前序分支命中后不再进入后续分支。

### SIF

见上文「单行条件语句 SIF」。注意 `SIF` 不是块结构，不能嵌套控制多行。

### SELECTCASE / CASE / CASEELSE / ENDSELECT

```erb
SELECTCASE 表达式
    CASE 值                  ; 单值，可逗号分隔多个：CASE 值1, 值2
    CASE 起始 TO 终止        ; 范围
    CASE IS <= 值            ; 比较式
    CASEELSE                 ; 兜底，至多一个
ENDSELECT
```

- 装载期：CASE 条件字面量类型必须与 SELECTCASE 表达式一致，否则 `NotMatchCaseTypeAndSelectcaseType`（`Runtime/Script/Loader/ErbLoader.cs:1216-1220`）；CASEELSE 之后不得再出现 CASE（`InvalidCaseAfterCaseelse`，1 级警告，`Runtime/Script/Loader/ErbLoader.cs:1164-1166`）；
- 运行期：`SELECTCASE_Instruction` 从左到右逐个 CASE、每个 CASE 内逐个条件求值，命中即停；没有命中跳 CASEELSE，再没有跳 ENDSELECT（`Runtime/Script/Statements/Instraction.Child.cs:3271-3335`）。CASE 内的 `IS` 代表 SELECTCASE 的值。

### REPEAT～REND 与 FOR～NEXT

```erb
REPEAT 次数          ; 计数器是内置变量 COUNT，从 0 起
    ; …
REND

FOR 变量, 初始值, 终止值, 步长   ; 步长可省略，默认 1
    ; …
NEXT
```

- `REPEAT n` 等价于 `FOR COUNT, 0, n, 1`（同一指令类实现，`REPEAT_Instruction(bool fornext)`，`Runtime/Script/Statements/Instraction.Child.cs:3098-3127`）；
- 循环在「计数变量到达终止值之前」继续：即**终止值不包含在内**，步长可负；
- REPEAT 嵌套仅警告（见上）；循环变量与其他循环重名时只有同为 `COUNT` 的情形会被警告，其余由脚本作者自查。

### WHILE～WEND 与 DO～LOOP

```erb
WHILE 条件        ; 前置判断：条件不成立时一次也不执行
    ; …
WEND

DO                ; 后置判断：至少执行一次
    ; …
LOOP 条件
```

`WEND` 条件非 0 则跳回 WHILE（`Runtime/Script/Statements/Instraction.Child.cs:3549-3562`）；`LOOP` 条件非 0 则跳回 DO（`Runtime/Script/Statements/Instraction.Child.cs:3564-3577`）。

### BREAK 与 CONTINUE

| 语句 | 作用 | 实现要点 |
| --- | --- | --- |
| `BREAK` | 跳出当前循环 | 找到装载期记下的最近循环头；对 REPEAT/FOR 会**先把计数器加一步**（「eramakerではBREAK時にCOUNTが回る」，`Runtime/Script/Statements/Instraction.Child.cs:3457-3459`），对 WHILE/DO 直接跳 |
| `CONTINUE` | 进入下一轮 | REPEAT/FOR：计数器 +步长，未到终点跳回循环头，已到终点跳到循环结束行；WHILE：重新求 WHILE 条件；DO：重新求 LOOP 行条件 |

`CONTINUE` 之后循环结束条件仍会被检查，因此 `CONTINUE` 不会造成额外多循环一轮。

### TRYC～CATCH～ENDCATCH

```erb
TRYCCALL 可能不存在的函数
    ; 函数存在：调用后执行这里
CATCH
    ; 函数不存在：执行这里
ENDCATCH
```

仅用于捕获「函数不存在」；函数体内运行时错误不会被捕获。前缀命令家族：`TRYCJUMP`、`TRYCGOTO`、`TRYCCALLFORM`、`TRYCJUMPFORM`、`TRYCGOTOFORM`。装载期强制 CATCH 紧跟 TRYC 块、ENDCATCH 紧跟 CATCH（`Runtime/Script/Loader/ErbLoader.cs:1242-1268`）。

### TRYCALLLIST / TRYJUMPLIST / TRYGOTOLIST ～ FUNC ～ ENDFUNC

```erb
TRYCALLLIST
    FUNC 函数1
    FUNC 函数2
ENDFUNC
```

依次尝试 `FUNC` 列出的函数名，调用第一个存在的那个，全部不存在则落到 ENDFUNC 之后。块内只允许 `FUNC`/`ENDFUNC`（`Runtime/Script/Loader/ErbLoader.cs:1000-1007`）；`FUNC` 行必须带参数列表；`TRYGOTOLIST` 的 FUNC 目标不能带参数或子名（`Runtime/Script/Loader/ErbLoader.cs:1410-1423`）。TRYCALLLIST/TRYJUMPLIST 的使用会使所有函数被强制按解释执行路径处理（`useCallForm`，`Runtime/Script/Loader/ErbLoader.cs:1524-1525`）。

### PRINTDATA / STRDATA / DATALIST 系列

```erb
PRINTDATA
    DATA 文本1
    DATAFORM 文本{A}
    DATALIST
        DATA 随机
        DATA 多行组
    ENDLIST
ENDDATA
```

- 块内只允许 DATA 系行；`DATA` 是一行、`DATALIST…ENDLIST` 是一组（随机抽一整组）；块内不得定义 `$` 标签（`CanNotLabelDefineInSyntax`，`Runtime/Script/Loader/ErbLoader.cs:952-975`）；
- PRINTDATA 系（8 个变体，按 L/W/D/K 组合）与 STRDATA 之间禁止嵌套；块为空时警告但可通过；
- 运行期随机抽取后整体跳过到 ENDDATA（STRDATA 的实现见 `Runtime/Script/Process.ScriptProc.cs:756-782`）。

## 与源码的差异/备注

1. ecd/ERB_Compound_Statements 说「REPEAT 嵌套时若使用不当可能出现无限循环，注意计数器」，把嵌套描述为可行但危险；源码实际是 1 级警告 `NestedRepeat`（eramaker 完全不支持）。zh/ERB_File_Format 的「REPEAT 语句不支持嵌套」是 Eramaker 时代的说法。
2. ecd 说 `BREAK`「立即跳出当前循环」——对 WHILE/DO 正确；对 REPEAT/FOR，源码在跳出前会把计数器递增一步（`Runtime/Script/Statements/Instraction.Child.cs:3457-3459`，eramaker 兼容行为），若循环体在 BREAK 后读取 `COUNT` 可观察到该副作用，文档未提及。
3. ecd 说 `FOR`「循环变量不能与其他嵌套循环重名」——源码只对 `COUNT` 作为 FOR 计数变量且与外层 REPEAT/FOR 冲突（且都是常量下标）的情形给出警告 `RepeatInsideFor`（`Runtime/Script/Loader/ErbLoader.cs:1020-1032, 1056-1075`），其他重名不做检查。
4. ecd/ERB_Statements 说「`SIF` 的下一行不能是空行、注释行或标签行，否则会出错**或失去意义**」——源码分级：标签行/复合块/函数行是 2 级错误（NothingAfterSif、FuncCanNotAfterSif、LabelCanNotAfterSif），隔空行的普通语句可运行但有 `EmptyAfterSif` 警告（0 级，默认不可见）。
5. ecd/ERB_Statements 的跳转语句节把 `JUMP`/`CALL`/`RETURN` 归为「跳转语句」，ecd/ERB_Compound_Statements 又把 TRYC 系列为「复合语句」——两页对同一族的归类有重叠，实际实现上 TRYC 系是带 PARTIAL 标志的指令（同 IF/FOR），与 CALL 系命令分属两处实现。
6. ecd 说复合语句「都成对出现……漏写 ENDIF/REND/NEXT/WEND 会直接报错」，与源码一致；但文档未列 PRINTDATA 的 ENDDATA、TRYCALLLIST 的 ENDFUNC、NOSKIP 的 ENDNOSKIP、SELECTCASE 的跨块闭合（IF 未闭合时遇到 CASE 会沿栈弹出并报 `InstructionNotClosed`，`Runtime/Script/Loader/ErbLoader.cs:1152-1163`）。
7. zh 套件的 ERB_Statements.md 与 ERB_Compound_Statements.md 页面为空壳（只有标题，无正文），无从交叉核对；SIF/IF/REPEAT 的教程内容实际位于 zh/ERB_File_Format.md，内容与 ecd 一致但更简略（缺 `'=` 复合赋值、FOR/WHILE/DO/SELECTCASE/TRYC 等扩展语法）。
