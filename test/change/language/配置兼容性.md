## 当前读取但未生效的配置

以下配置项可能出现在 `emuera.config`、`CSV/_default.config` 或 `CSV/_fixed.config` 中。当前实现可以读到它们，但还没有完整接入对应的 C++ 行为：

### 文件与装载

- `大文字小文字の違いを無視する`
  - C# 控制命令、变量、函数等名称的大小写处理。
  - 当前 C++ 装载器仍按固定的大小写不敏感逻辑工作，配置值没有完全控制该行为。
- `読み込み順をファイル名順にソートする`
  - C# 控制文件装载排序。
  - 当前 ERB 装载器始终使用自己的大小写不敏感排序规则，配置值未接入。
- `_Replace.csvを利用する`
  - C# 控制 `_Replace.csv` 是否读取。
  - 当前 C++ 尚未实现 `_Replace.csv` 的完整加载和覆盖语义。

### 解析与警告

- `ロード時に引数を解析する`
  - C# 的 `NO` / `ONCE` / `YES` 会控制加载期参数解析策略。
  - 当前 C++ 统一在加载期构建 AST，枚举值不会改变解析流程。
- `表示する最低警告レベル`
  - C# 控制显示的最低警告等级。
  - 当前结构化诊断已收集，但该配置尚未统一过滤所有显示和日志出口。
- `関数が見つからない警告の扱い`
- `関数が呼び出されなかった警告の扱い`
- `eramaker互換性に関する警告を表示する`
  - 当前仅部分保留诊断，配置值尚未完整控制警告策略。
- `システム関数の上書きを許可する`
- `システム関数が上書きされたとき警告を表示する`
- `同名の非イベント関数が複数定義されたとき警告する`
  - 当前函数登记/覆盖逻辑存在，但上述配置尚未完整控制覆盖和告警策略。

- `TIMESの計算をeramakerにあわせる`
- `キャラクタ変数の引数を補完しない`

## 已修正的配置行为

- `_default.config` 与 `default.config` 回退文件名。
- `_fixed.config` 与 `fixed.config` 回退文件名。
- 配置读取顺序：`_default.config` → `emuera.config` → `_fixed.config`。
- `サブディレクトリを検索する` 的 C# 默认值为 `NO`。
- `_Rename.csvを利用する` 关闭时不加载 `_Rename.csv`。
- `オートセーブを行なう`、`販売アイテム数`、`PRINTCを並べる数`、`イベント関数のCALLを許可する` 使用 C# 正式键名。
- 界面布尔配置按正式日文键优先读取；明确的 `NO` 不会被英文别名或默认值覆盖。
