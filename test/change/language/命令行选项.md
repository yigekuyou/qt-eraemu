# 移植差异 · Linux 命令行选项

> 对应 C# 参考实现的启动选项。规则见 [`../README.md`](../README.md)。

## 调试模式启动参数

C# Emuera 的 `Program.cs` 使用旧式单短横线参数 `-Debug`，并注册了大小写别名。Qt/C++ 移植按 Linux 命令行规范统一使用长选项：

- 唯一有效参数：`--debug`
- `-debug`、`-Debug`、`-DEBUG`、`--Debug` 均无效，不会开启调试模式
- QML 的调试窗口、`\DEBUG` 控制台命令和调试相关 UI 只在参数严格为 `--debug` 时可用
- 未带 `--debug` 时，输入 `\DEBUG` 会显示：`デバッグウインドウは--debug引数付きで起動したときのみ使えます`

实现位置：`src/eraengine/eraengine.cpp` 的 `EraEngine::debugMode()`。匹配使用 Qt 的 `QString` 精确比较，保证大小写和短选项都不会被宽松接受。
