# 移植差异 · 调试与错误

> 对应 `test/data/language/调试与错误.md`（该文档只保留 C# 语义）。规则见 [`../README.md`](../README.md)。

- **本移植的诊断模型（分级 + 代码，已实现）**：C# 侧只有
   `ParserMediator.Warn(str, pos, level, isError)` 的 0～3 级 + 文本；本移植把它结构化为
   `DiagSeverity{Info,Warning,Error}` + 稳定 `code`
   （`unknown-instruction` / `expr-parse` / `arg-check` / `sharp-line` / `decl-error` / `preprocess`）
   + `position`（`"文件:行[:列]"`）+ 原文片段，见 `src/eraengine/GameData/ast/parse_diagnostic.h`；
   装载结束按「级别 + 代码」汇总（`ParseDiagnostics::summarize()`，例：
   `警告 146（arg-check 105 / expr-parse 28 / unknown-instruction 13）`）。
   同时**表达式节点携带源码区间** `ExpressionNode::span()`（`SourceSpan`）：因表达式 AST 按文本
   缓存并跨行共享（`EraParseTable::m_astCache`），区间记为**表达式文本内偏移**（缓存安全），
   绝对列由调用方按行的 `ScriptPosition` 换算；解析失败点（如三元缺 `#`）报出具体列。
   回归：`src/eraengine/test/test_ast_span.cpp`、`test_parse_diagnostic.cpp`。
