# 文件参考：配置文件（emuera.config）

> 来源：ecd/docs/Config_Settings.md（配置项详解）、ecd/docs/Config_File.md（Config 文件参考）、ecd/docs/Config.md 与 zh/Config.md（强制配置项目）；交叉核对 zh 套件 Config_Settings.md、Config_File.md、Config.md

## 概述

`emuera.config` 是 Emuera 的配置文件，首次运行时在 exe 同目录自动生成。它决定窗口、字体、颜色、存档方式、解析警告、兼容性开关等全部运行时行为；游戏作者还可以用 `CSV/_default.config` 提供推荐值、`CSV/_fixed.config` 强制锁定关键项。配置项名为日文原文（本分支每项带英文别名），文件为纯文本，每行形如 `配置项:值`，`;` 开头的行是注释。

本仓库源码中：配置项定义在 `Runtime/Config/ConfigData.cs`（`setDefault`），装载/保存与校验在 `Runtime/Config/Config.cs` 与 `Runtime/Config/ConfigData.cs`，配置枚举在 `Runtime/Config/ConfigCode.cs`。

## 配置文件的装载

```text
// Runtime/Runtime/Config/ConfigData.cs:691-716  LoadConfig()
defaultConfigPath = CsvDir + "_default.config"   // 不存在时回退 default.config :695-696
fixedConfigPath   = CsvDir + "_fixed.config"     // 不存在时回退 fixed.config   :697-698
loadConfig(defaultConfigPath, fix=false)         // :700
loadConfig("emuera.config",   fix=false)         // :701  configPath = ExeDir + "emuera.config" :21
loadConfig(fixedConfigPath,   fix=true)          // :702  后读者覆盖先读者；fix=true 时解析成功的项打上 Fixed 标记
Config.SetConfig(this)                           // :704  应用到 Config 静态属性
若 emuera.config 不存在或更新键变化 → SaveConfig()  // :705-714
```

逐行解析规则（`Runtime/Config/ConfigData.cs:718-798` `loadConfig`）：

- 空行与 `;` 注释行跳过（`:732-733`）；按 `:` 分隔取「配置项:值」（`:735-737`）。
- `テキストエディタ`（编辑器路径）特殊处理：值中允许再含 `:`（如 `C:\...`），后续 token 全部拼回值里（`:757-772`）；`エディタに渡す行指定引数` 直接原样取值以保留半角空格（`:773-778`）。
- 旧配置项 `DRAWLINEを常に新しい行で行う`（CompatiDRAWLINE）自动映射为 `ver1739以前の非ボタン折り返しを再現する`（`:743-747`）。
- 解析模式（命令行分析）下 `履歴ログの行数` 被强制改为 10000（`:779-783`）。
- `_fixed.config` 中解析成功的项标记 `Fixed = true`，此后配置对话框不能再修改（`:784-785`，`ReLoadConfig` 在重载前先解除全部 Fixed，`:677-689`）。

读取顺序（后读覆盖先读）：`CSV/_default.config` → `emuera.config` → `CSV/_fixed.config`。与文档（zh/Config.md、ecd/Config.md）一致；但源码额外支持不带下划线的 `default.config` / `fixed.config` 作为回退（`Runtime/Config/ConfigData.cs:695-698`），文档声称「没有下划线的文件名不会被加载」——对本分支源码不成立。

`_default.config` 用于给出推荐值但不剥夺用户自定义权（存在 `emuera.config` 时被其覆盖）；`_fixed.config` 应尽量少放选项，只锁定影响显示规格的关键项（如「不在按钮中间折行」「_Replace.csv を利用する」「背景色/文字色」）。

## 配置项总表（按源码 `Runtime/Config/ConfigData.cs:45-176` 的默认值）

### 基础与解析

| 配置项 | 默认值 | 影响 |
|---|---|---|
| `大文字小文字の違いを無視する` | `YES` | 命令/变量名是否忽略大小写；决定全局字符串比较模式（`Runtime/Config/Config.cs:29-39`） |
| `全角スペースをホワイトスペースに含める` | `YES` | 全角空格是否算空白（可禁止用全角空格缩进） |
| `関数・属性については大文字小文字を無視しない` | `NO` | 函数名/属性名区分大小写（Eramaker 规格） |
| `内部で使用する東アジア言語` | `JAPANESE` | 内部编码区域：`JAPANESE`→CP932、`KOREAN`→949、`CHINESE_HANS`→936、`CHINESE_HANT`→950（`Runtime/Config/Config.cs:181-192`） |

## 与 _Replace.csv 的关系

`_Replace.csv` 的条目在源码里也是一组配置项（`replaceArray`，`Runtime/Config/ConfigData.cs:186-201`），但只在 `_Replace.csvを利用する` 为 YES 时由 `LoadReplaceFile` 填充（`Runtime/Script/Process.cs:111-128`），再经 `Config.SetReplace` 生效（`Runtime/Config/Config.cs:563-583`）。它们不能写入 `emuera.config`（配置对话框不提供这些项）。详见 language/CSV文件.md 的 _Replace.csv 一节。

## 与源码的差异/备注

1. **`セーブデータをUTF-8で保存する` 已被移除**：ecd/Config_Settings.md 与 ecd/Config_File.md 均收录该项（默认 NO）；emuera.em 源码激活版 `setDefault` 中没有它（仅存于注释掉的旧代码 `Runtime/Config/ConfigData.cs:269`），且编码恒为 UTF-8 BOM（`Runtime/Config/Config.cs:18-19`）。
2. **`描画インターフェース:WINAPI` 不可用**：文档列 WINAPI 为可选值；源码检测到 WINAPI 时弹「不支持」并强制回 TEXTRENDERER（`Runtime/Config/Config.cs:219-223`）。
3. **`default.config` / `fixed.config` 回退**：文档（zh/Config.md、ecd/Config.md）说无下划线的文件名不会被加载；源码在 `_default.config`/`_fixed.config` 不存在时会尝试加载无下划线版本（`Runtime/Config/ConfigData.cs:695-698`）。
4. **`最大スキップフレーム数` 失效**：项仍会写入/读出配置文件，但应用代码与属性已被注释（`Runtime/Config/Config.cs:67,482`），对本分支无效。
5. **`DRAWLINEを常に新しい行で行う`**：文档未记载；源码将其映射为 `ver1739以前の非ボタン折り返しを再現する`（`Runtime/Config/ConfigData.cs:743-747`）。
6. **文档未记载的源码配置项**：`デバッグコマンドを使用した時にMASTERの名前を変更する`（默认 YES）、`最終更新コード`（内部更新键）、上表全部 EE/私家版扩展项。
7. **默认值核对**：ecd/Config_File.md 的默认值表与源码一致（窗口 760×480、FPS 5、日志 5000、PRINTC 25/3、字体 `ＭＳ ゴシック` 18/19、颜色 192,192,192 / 0,0,0 / 255,255,0、编辑器 notepad、警告等级 1 等）；ecd/Config_Settings.md 注明「默认值以 ConfigData.cs 为准」并同样一致。zh/Config.md 仅描述 `_fixed.config`/`_default.config` 机制，无默认值表，与 ecd/Config.md 内容相同（繁简措辞差异）。
8. **枚举取值来源**：`ロード時に引数を解析する` 的三个值（NO/ONCE/YES）、警告处理四值（IGNORE/LATER/ONCE/DISPLAY）、绘制接口三值、编辑器四值均定义于 `Runtime/Config/ConfigCode.cs:3-39`。
