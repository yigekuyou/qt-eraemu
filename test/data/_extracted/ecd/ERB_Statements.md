# ERB 的语句 ​

语句是脚本里的一个处理单位。EraBasic 遵循“一行一句”，除特殊行外，每一行就是一条语句。本页介绍简单语句（不能再拆出下级结构）；需要控制多行的结构见复合语句。

## 语句的种类 ​

|种类|说明|例子|

|赋值语句|把值装进变量|`A = 10`|
|命令语句|让引擎做事|`PRINTL Hello`|
|跳转语句|改变执行位置|`GOTO Label`|
|单行条件语句|条件成立才执行下一行|`SIF A > 0`|
|注释|不执行，供人阅读|`; 说明`|

## 赋值语句 ​

把右边的值装进左边的变量：

erb
```
`A = 10
S = "文本"
A = A + 1        ; 先算右边，再存回左边
CFLAG:0:5 = 100  ; 也可以给数组元素赋值`
```

赋值号左右两边的类型必须一致：数值变量只能装数值，字符串变量只能装字符串。

复合赋值是简写：

erb
```
`A += 1   ; 等价于 A = A + 1
A -= 1
A *= 2
A /= 2
A %= 2`
```

字符串用 `'=` 进行赋值：

erb
```
`S '= "文本" + TOSTR(A)`
```

## 命令语句 ​

命令是引擎提供的操作，后跟参数：

erb
```
`PRINTL Hello
INPUT
QUIT`
```

参数的具体格式由命令决定，完整的参数类型见值类型规范。

## 单行条件语句：SIF ​

`SIF` 只在条件成立时执行下一行：

erb
```
`SIF A > 0
  PRINTL A 是正数`
```

它等价于：

erb
```
`IF A > 0
  PRINTL A 是正数
ENDIF`
```

>
`SIF` 的下一行不能是空行、注释行或标签行，否则会出错或失去意义。

## 跳转语句 ​

erb
```
`GOTO 标签名`
```

跳转目标是标签（`$名称`）或函数（`@名称`）。另外：

- `JUMP 函数名`：跳到函数，且不返回；
- `CALL 函数名`：调用函数，执行完返回；
- `RETURN`：从当前函数返回。

## 注释 ​

erb
```
`; 整行注释
A = 10  ; 行末注释`
```

|写法|说明|

|`;`|普通注释|
|`;!;`|在 Emuera 中有效，在 Eramaker 中被视为注释|
|`;#;`|只在调试模式下执行|

## 变量声明（预处理指令） ​

变量不是“语句”，而是通过 `#` 开头的预处理指令声明：

erb
```
`#DIM A          ; 数值变量
#DIMS S         ; 字符串变量
#DIM FLAG, 100  ; 100 个元素的数值数组`
```

这些声明必须紧跟在函数定义之下，详见函数与预处理指令。
