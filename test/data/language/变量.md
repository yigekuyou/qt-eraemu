## 概述

变量是 EraBasic 中存放数据的基本单元。Eramaker 时代的变量体系（A~Z、FLAG、角色变量等）在 Emuera 中被完整保留，并通过位标志化的 `VariableCode` 枚举统一管理类型（整数/字符串）、维数（0~3 维）、是否角色数据、是否可保存等属性；再叠加 Emuera 专属的局部变量（LOCAL/ARG）、伪变量（RAND/CHARANUM）、CSV 派生变量与用户自定义变量（`#DIM`/`#DIMS`）。所有变量在运行期由 `VariableData`（全局数据）+ `CharacterData`（每角色数据）+ 各类 `VariableToken` 子类承载，求值与赋值经 `VariableTerm` → `VariableToken.Get/Set` 完成。

## 常量的表示

Emuera 接受以下整数字面量（仅可用于常量位置，不能作用于表达式）：

```erb
X = 32        ;十进制
X = 0b100000  ;二进制
X = 0x20      ;十六进制
X = 1p5       ;1 × 2^5
X = 13e3      ;13 × 10^3 = 13000
```

- `1p5` 风格记号适合与位运算符配合，例如 `IF (A & 1p0)||(A & 1p3)`。
- `13e(A + 1)` 这类把表达式放在 `e`/`p` 之后的写法是错误。
- 出于与 Eramaker 的兼容性，不接受八进制：`012` 解释为 `12` 而非 `10`。

## 变量的分类体系

### 按作用域

|作用域|说明|定义方式|
|---|---|---|
|私有变量|只在定义它的函数内可用|函数声明下 `#DIM` / `#DIMS`|
|局部变量|`LOCAL`/`LOCALS`/`ARG`/`ARGS`，按函数名区分|内置，`#LOCALSIZE(S)` 可调尺寸|
|广域变量|ERB 全部位置可用|ERH 中 `#DIM` / `#DIMS`|
|全局变量|跨存档共享，由 `SAVEGLOBAL`/`LOADGLOBAL` 读写 `global.sav`|ERH 中 `#DIM GLOBAL`（可加 `SAVEDATA`）|

### 按类型与形态

- 类型：整数（内部为 64 位 `long`）或字符串，由 `VariableCode.__INTEGER__`/`__STRING__` 标志决定（`Runtime/Script/Statements/Variable/VariableToken.cs:20`）。
- 形态：非数组（0 维）、一维/二维/三维数组、角色变量（第一维为角色注册号）、伪变量（形如变量实为计算）。

```text
// 维度与类别的判定（VariableToken.cs:15-87 构造函数伪代码）
VariableToken(VariableCode varCode):
    VariableType = (varCode & __INTEGER__) ? typeof(long) : typeof(string)
    Dimension = 1 if __ARRAY_1D__; 2 if __ARRAY_2D__; 3 if __ARRAY_3D__   // :29-34
    IsGlobal    = (code == GLOBAL || code == GLOBALS)                     // :28
    IsSavedata  = GLOBAL/GLOBALS 或 __SAVE_EXTENDED__ 标志                 // :37-43
    // eramaker 系变量的保存判定：按 “角色数据? × 整数/字符串? × 数组维数?”
    // 取 VarCodeInt < __COUNT_SAVE_*__ 阈值决定是否写入存档          // :44-86
```

### 角色注册编号与角色编号

- `CharaXX.csv` 中登记的是「角色编号」（模板）；只有被 `ADDCHARA` 实例化后才得到「角色注册编号」（实例）。
- 游戏开始时只有主角实例化（注册号 0）；`ADDCHARA` 得到的实例按注册顺序编号。
- `DELCHARA` 删除后，后续 `ADDCHARA` 会复用空出的注册号——注册号是一个从 0 开始连续的角色实例列表索引。
- `MASTER`/`TARGET`/`ASSI`/`PLAYER` 存的是注册编号，可能与 `CharaXX.csv` 中的编号不同。

### 角色变量的省略记法

角色变量的第一维可省略，省略时自动补 `TARGET`；第二维也可省略，省略时补 0：

```erb
EXP:0      ;等价于 EXP:TARGET:0
CFLAG:3:1  ;角色注册号 3 的 CFLAG:1
```

## 角色变量

每个角色实例持有独立的数组集合，访问 `ABL:TARGET:0` 时先按第一维取出 `CharacterData`，再取其中该变量的数组：

```text
// 角色一维整数变量的 Get/Set 路径（VariableToken.cs:910-961 CharaInt1DVariableToken）
GetIntValue(exm, [chara, index]):
    chara = varData.CharacterList[chara]          // 按注册号取角色实例
    return chara.DataIntegerArray[VarCodeInt][index]
SetValue(value, [chara, index]):
    varData.CharacterList[chara].DataIntegerArray[VarCodeInt][index] = value
GetArrayChara(charano):                            // 供 VARSIZE/数组指令使用
    return varData.CharacterList[charano].DataIntegerArray[VarCodeInt]
```

- `CharacterData` 构造时按 `ConstantData.CharacterIntArrayLength` 等表为每类变量分配数组（`Runtime/Script/Statements/Variable/CharacterData.cs:27-92`）；用户角色变量在 `UserDefCVarDataList` 中按声明顺序各占一格（`Runtime/Script/Statements/Variable/CharacterData.cs:53-91`，由 `UserDefinedCharaVariableToken.GetArrayChara` 取用，`Runtime/Script/Statements/Variable/VariableToken.cs:401-404`）。
- 新角色从 `CharacterTemplate` 初始化：NO/NAME/CALLNAME/NICKNAME/MASTERNAME、MAXBASE 与 BASE 同值、各素质/经验/能力/刻印/相性/CFLAG/EQUIP/JUEL/CSTR（`Runtime/Script/Statements/Variable/CharacterData.cs:95-166`）；RELATION 先全部填 `_replace.csv` 的 Relation 默认值再被模板覆盖（`Runtime/Script/Statements/Variable/CharacterData.cs:124-128`）。
- 越界检查：角色号与各维下标在 `CharaVariableToken.CheckElement` 中验证（`Runtime/Script/Statements/Variable/VariableToken.cs:278-286`），总元素数为 0 时整个变量视为禁用（`Runtime/Script/Statements/Variable/VariableToken.cs:249-256`）。

### 污渍（STAIN）的位表示

`Stain` 用一个整数按位记录多种污渍的组合（例如 A/B/C/D 对应 1/2/4/8，值 5 = A+C）。判断用 `&`（`Stain:Target:0 & 4 == 4` 表示第 4 位污渍存在），添加用 `|` 或 `|=`（已存在则值不变）。常规四则运算对这类数据没有意义。

## 多维数组变量（DA~DE、DITEMTYPE、TA、TB）

- `DA`~`DE`、`DITEMTYPE`：固定二维整数数组，默认 100×100；`TA`/`TB`：固定三维整数数组，默认 100×100×100（`Runtime/Script/Data/ConstantData.cs:193-201` 把所有 2D/3D 长度打包为 `(100L<<32)+100L` / `(100L<<40)+(100L<<20)+100L`）。
- 访问时所有下标不可省略：`DITEMTYPE:1:2`、`TA:1:2:3`（`Runtime/Script/Statements/Variable/VariableParser.cs:135-151` 对 2D/3D 变量缺下标直接报错）。
- `VariableSize.csv` 可改尺寸（2D 写 `DA,100,200` 形式），`VARSIZE` 指令把各维长度依次放入 `RESULT:0`、`RESULT:1`（、`RESULT:2`）。
- 两套文档均将其标注为「已弃用，建议改用 `#DIM`/`#DIMS`」。
- 注意：与 Eramaker 的角色二维数组不同，这些数组的第一维不是角色注册号，尺寸不随 `CHARANUM` 变化。

## 局部变量 LOCAL / LOCALS / ARG / ARGS

- `LOCAL`（整数）基本尺寸 1000，`LOCALS`（字符串）100，可在 `VariableSize.csv` 中修改（整数下限 1，非局部整数变量下限 100：`Runtime/Script/Data/ConstantData.cs:311-331`）。
- `#LOCALSIZE <n>` / `#LOCALSSIZE <n>` 可为单个函数指定尺寸（必须为大于 0 的整数；事件函数中指定会被忽略并警告）。
- **不随函数调用初始化**：每个函数名对应一份独立的 `LOCAL`，内部按「`LOCAL@函数名`」键保存。同名函数（如多个事件函数）共享同一份；递归调用也共用；函数返回后值保留。
- `ARG`/`ARGS` 用于接收函数参数，尺寸自动扩到参数个数（且不小于 `VariableSize.csv` 指定值）；未定义参数的函数里使用会得到警告。
- 均不保存。
- 可用 `LOCAL@函数名`（关联名）从其他函数访问另一函数的 LOCAL，但这是调试用途：官方文档不建议，且函数名含运算符时报错。

```text
// 关联名（LOCAL@函数名）的解析（IdentifierDictionary.cs:484-543 GetVariableToken 伪代码）

```

非数组、只读、不保存：`GAMEBASE_AUTHOR`（作者）、`GAMEBASE_INFO`、`GAMEBASE_YEAR`、`GAMEBASE_TITLE`（字符串）；`GAMEBASE_GAMECODE`、`GAMEBASE_VERSION`、`GAMEBASE_ALLOWVERSION`、`GAMEBASE_DEFAULTCHARA`、`GAMEBASE_NOITEM`（整数）。注册于 `Runtime/Script/Statements/Variable/VariableData.cs:292-308`（另有扩展的 `GAMEBASE_URL`/`GAMEBASE_VERSIONNAME`，见「差异」节）。

### 与 csv 有关的其他变量

### 指定变量尺寸（VariableSize.csv）

放在 CSV 目录的 `VariableSize.csv` 可修改既有变量的元素数；尺寸写 `-1`（或任意负值）表示**禁用**该变量：

```text
// ConstantData.cs:219-256 loadVariableSizeData / :259-330 changeVariableSizeData 伪代码
每行: 变量名, 尺寸1[, 尺寸2[, 尺寸3]]
    仅数组变量（1D/2D/3D）可调；CALC 伪变量与 RANDDATA 不可调（:279-283）
    length <= 0:
        0      → 警告“数组长度为 0”，忽略
```

被禁用的变量在 ERB 中赋值/引用都会报错（`Runtime/Script/Data/IdentifierDictionary.cs:530-535`：`IsForbid` 且 `CanForbid` → CodeEE）；系统内部需要该变量时赋值被忽略、读取恒为 -1（如被禁用的 `MONEY`、`NEXTCOM`）。

## 保存与加载

- 普通存档保存 eramaker 系阈值内的变量 + `__SAVE_EXTENDED__` 标志变量 + 用户 `SAVEDATA` 变量：`VariableData.SaveToStream`（`Runtime/Script/Statements/Variable/VariableData.cs:681-692`）按 str/int/intArray/strArray 四段定长写出；扩展段 `SaveToStreamExtended`（`Runtime/Script/Statements/Variable/VariableData.cs:707-778`）按 `VariableIdentifier.GetExtSaveList` 的分类逐个写出（字符串 2D/3D 数组的保存标注为「未实现」）。
- `GLOBAL`/`GLOBALS` 与用户 `#DIM GLOBAL` 变量由 `SAVEGLOBAL`/`LOADGLOBAL` 单独读写 `global.sav`，不随普通存档保存；`SetDefaultGlobalValue` 负责其初始化（`Runtime/Script/Statements/Variable/VariableData.cs:519-530`）。
- `RANDDATA`（长度 625，`Runtime/Script/Data/ConstantData.cs:187`）保存随机数状态：`DUMPRAND` 写入（`Runtime/Script/Statements/Variable/VariableEvaluator.cs:51-54`）、`INITRAND` 读出（`:46-49`）。
- 局部变量、`LOCAL`/`ARG` 系、用户静态变量在加载/重置时由 `SetDefaultLocalValue` 清零或恢复初始值（`Runtime/Script/Statements/Variable/VariableData.cs:532-538`）。

## 用户自定义变量（#DIM / #DIMS）

### 私有变量

在函数声明之下书写：

```erb
@FIND_CSTR(KEY, VALUE)
#FUNCTION
#DIM LCOUNT
#DIM KEY
#DIMS VALUE
SIF KEY < 0 || KEY >= VARSIZE("CSTR")
  RETURNF -1
FOR LCOUNT, 0, CHARANUM
  SIF LCOUNT == MASTER
    CONTINUE
  SIF CSTR:LCOUNT:KEY == VALUE
    RETURNF LCOUNT
NEXT
```

- `#DIM(S) <变量名>, <元素数>{, <元素数>{, <元素数>}}`：变量名不以数字开头、仅可含 `_`；元素数为 1~1000000 的整数或常量表达式，省略为 1；最多 3 维（写第 4 个元素数报错）。
- 定义后不保存，初始值 0 或空串；也可作为函数参数并给初始值（参数带初始值时只能是常量，见 `Runtime/Script/Loader/ErbLoader.cs:648-656`）。

### 初始值

```erb
#DIM HOGE = 1,2,3        ;省略元素数 → 元素数为 3
#DIM PUGE,100 = 4,5,6    ;元素数 100，前 3 个被赋值
#DIM HIGE,1 = 7,8,9      ;错误：初始值个数 > 元素数
#DIMS SHOGE = "A", "B", "C"
```

多维数组不能定义初始值；初始值必须是常量表达式（求值后须为 `SingleTerm`，否则报错）。

### DYNAMIC（动态变量）

`#DIM(S) DYNAMIC` 使变量在函数每次调用时分配、返回时销毁：递归时各层独立，但比默认的静态分配慢。`RESTART`（回到函数开头）不会重置动态变量。默认（不加 DYNAMIC）即静态（STATIC）：与函数共存亡、值跨调用保留。

### CONST（常量）

`#DIM CONST HOGE = 1,2,3` 定义一维数组常量：声明时必须给初始值，且个数必须与元素数一致；不可赋值；不能与 `GLOBAL`、`SAVEDATA`、`REF`、`DYNAMIC`、`CHARADATA` 同用。

### REF（引用型变量）

`#DIM REF HOGE,0`（0 表示该维不指定尺寸，一维连 `,0` 都可省）声明引用型变量；本身无实体，操作它即操作按引用传入的变量（ver1.815 起 `REF` 指令已不可用）。引用匹配规则（`Runtime/Script/Statements/Variable/VariableToken.cs:514-539 MatchType`）：不能引用伪变量、常量；类型（整数/字符串）、维数必须一致；非私有的 REF 不能引用私有/局部变量；默认不能引用角色变量（按引用传角色变量时需显式允许）。

### ERH 中的广域变量

在 ERH（头文件）中写的 `#DIM(S)` 是广域变量，ERB 任何位置可用；没有 DYNAMIC/STATIC 之分，不能用 REF，可用 CONST。另可用 ERH 专属关键字：

```erb
#DIM SAVEDATA MY_INT_ARRAY, 100        ;随存档保存
#DIMS CHARADATA C_STR_ARRAY, 100       ;角色变量（可加 SAVEDATA）
#DIM GLOBAL G_INT_ARRAY, 100           ;全局变量（SAVEGLOBAL/LOADGLOBAL 读写）
#DIM GLOBAL SAVEDATA GS_INT_ARRAY, 100 ;保存的全局变量 → global.sav
```

注意：`#DIMS SAVEDATA` 声明可保存的多维字符串变量（以及字符串角色变量的保存）必须启用「以二进制格式保存存档」配置。

### 限制条件

- 不能用与**指令**同名的名字定义变量（`#DIM PRINTFORM`、`#DIM SELECTCASE`、`#DIM CALL`、`#DIM RETURN`、`#DIM GOTO`、`#DIM SQRT`、`#DIM DATAFORM`、`#DIM NOSKIP`、`#DIM FUNC`、`#DIM ENDFUNC` 均报错）；与函数/预处理指令同名可以但不推荐。
- 与 `LOCAL@函数名` 不同，没有任何方法从函数外访问别的函数的私有变量（`Runtime/Script/Data/IdentifierDictionary.cs:489-501`：私有变量只在当前函数的 `ParentLabelLine` 上查找）。
- 与 csv 派生变量重名会得到警告（`Runtime/Script/Statements/Variable/VariableData.cs:399-400, 424-425`）。

## 关联名与 @ORIG

- 关联名指 `变量@函数名` 形式，目前只对 `LOCAL`/`LOCALS`/`ARG`/`ARGS` 有效：`LOCAL@EVENTFIRST:10` 引用 `@EVENTFIRST` 里的 LOCAL（实现见 `Runtime/Script/Data/IdentifierDictionary.cs:484-543`，`VariableIdentifier.GetVariableId` 在 `subKey` 非空时只查局部变量表，见 `Runtime/Script/Statements/Variable/VariableIdentifier.cs:269-286`）。属调试用途，官方不建议；对非局部变量加 `@` 直接报错。
- `@ORIG`：本代码库与两套文档中均**不存在**名为 `@ORIG` 的语法或机制（全源码无 `ORIG` 标识符，grep 无命中）。若上游文档（osdn wiki 其他条目）提到过它，也应视为未在当前 Emuera 源中实现的特性，勿与 `LOCAL@函数名` 混淆。

## 与 Eramaker 的行为差异

- `NAME` / `CALLNAME`：Eramaker 不允许赋值，Emuera 允许。
- `RAND` / `CHARANUM`：Eramaker 中可以赋值（会被保存/加载，但无意义）；Emuera 禁止赋值。
- Emuera 新增大量变量（LOCAL/ARG、多维数组、角色字符串变量、CSV 变量、伪变量等），完整清单见上文各表。

## 与源码的差异/备注

1. **ISTIMEOUT**：文档称「从 ver1815 起可能无法使用」，但当前源码仍完整实现（`Runtime/Script/Statements/Variable/VariableToken.cs:1461-1472`，读 `Console.IsTimeOut`），行为为 TINPUT 系超时返回 1。
2. **EMUERA_VERSION**：源码注册了伪变量 `EMUERA_VERSION`（`Runtime/Script/Statements/Variable/VariableToken.cs:1499-1513`，硬编码返回 "1.824.0.0"），两套文档的行为表均未收录。
3. **EE_CSV 扩展变量**：源码额外提供 `DAYNAME`/`TIMENAME`/`MONEYNAME`（`Runtime/Script/Statements/Variable/VariableData.cs:286-290`）与 `GAMEBASE_URL`/`GAMEBASE_VERSIONNAME`（`Runtime/Script/Statements/Variable/VariableData.cs:298-301`），文档未记载。
4. **CHARANUM 带下标**：文档备注「当指定任何元素时，将返回角色注册的数量」，但源码中 `CHARANUM` 是 0 维 CALC 变量（`Runtime/Script/Statements/Variable/VariableCode.cs:195`），解析器对 0 维变量带下标直接报错（`Runtime/Script/Statements/Variable/VariableParser.cs:172-175`），该备注应理解为 Eramaker 兼容性说明而非 C# 实现行为。
5. **RAND 的维数**：`RAND` 实际带 `__ARRAY_1D__` 标志（`Runtime/Script/Statements/Variable/VariableCode.cs:194`），行为表中「维数 0」指的是概念上的伪数组；`RAND:X` 缺参/参数为 0 在非 CompatiRAND 模式下于解析期即报错（`Runtime/Script/Statements/Variable/VariableParser.cs:158-169`），与文档一致；CompatiRAND 模式下 0/负参数的宽容行为文档未提。
6. **TSTRNAME 的 csv 文件名**：文档行为表写作「TEtr.csv」，为「TStr.csv」的排印错误（正文表格与 zh 版相同）。
7. **CDFLAG 默认尺寸**：文档「元素数量的默认值是 1.1」指第 2/3 维各为 1，对应源码 `CharacterIntArray2DLength[i] = (1L<<32)+1L`（`Runtime/Script/Data/ConstantData.cs:213-214`）。
8. **保存细节**：字符串 2D/3D 数组的扩展保存在源码中标注「未实现」（`Runtime/Script/Statements/Variable/VariableData.cs:735-737, 748-750`），与文档「多维字符串 SAVEDATA 需二进制保存选项」的说明吻合但更严格（即便开了二进制，内置字符串 2D/3D 变量也没有保存路径）。
9. **禁用变量**：文档只说「-1 禁用」，源码实际是「一切负值等价于 0（禁用），且要求变量带 `__CAN_FORBID__` 标志，否则仅警告拒绝」（`Runtime/Script/Data/ConstantData.cs:292-309`）；此外尺寸 0 的行会被警告并忽略。
10. **调试变量**：非调试模式下源码注册的是返回空串/0 的 Empty token（`Runtime/Script/Statements/Variable/VariableData.cs:331-342`），与文档「正常模式返回空字符串或 0」一致。
11. **RELATION 初始化**：文档只提到 `_replace.csv` 的 Relation 为默认值，源码还保证新建角色时先把整行填成该默认值再套用模板（`Runtime/Script/Statements/Variable/CharacterData.cs:124-128`）。
12. **zh 套件核对**：`zh/Variable.md`、`zh/EraBasic_Variables.md` 与 ecd 版内容一致（仅标题 `#` 排版差异）；`zh/Custom_Variable.md` 的章节名为旧译（「设置默认值」「参考类型变量」「来自函数外的干扰」），ecd 版改为「初始值的设定」「引用型变量」「函数外部的访问」并重写了部分译文，语义无冲突。
