# 兼容性与版本

> 来源：ecd/docs/Compatibility.md、ecd/docs/Difference.md、ecd/docs/Version_Index.md、ecd/docs/Terminology.md、ecd/docs/Glossary.md；zh 侧核对结果见文末。其中 Difference.md 与 Glossary.md 是 OSDN 原始 wiki 的翻译，Compatibility.md、Version_Index.md、Terminology.md 是 Era 中文文档的原创速查页。

## 概述

本主题回答两个问题：同一份脚本在 Eramaker 与 Emuera（及其改造版）中行为为何不同；某个行为/特性是从哪个版本开始存在或改变的。Eramaker 是-era 游戏的原始引擎，Emuera 与其兼容但有意识地修复了一批「bug 与不自然行为」，并通过一组「兼容性开关」（源码 `ConfigCode.Compati*`）让旧脚本可以还原旧行为。

## 与 Eramaker 的行为差异（ecd/Difference.md）

### 修复的 Bug 与不自然的行为

| 项 | Eramaker | Emuera |
|---|---|---|
| 数组最后一个元素 | 若最后一个元素非 0，读档会破坏数据（存/读规范不统一所致） | 不存在；以保存时规范为准。Eramaker 存 → Emuera 读不出问题，反之会重现 |
| 单目运算符 `-` | `-100 < 0` 这类表达式结果为「假」 | 不存在此问题 |
| 文件最后一行 | 无换行符的最后一行（CSV/ERB 皆是）被忽略 | 正常读取 |
| 数组多余元素 | `A:1:2 = 34` 把 34 赋给 `A:1`（多余下标忽略） | 报错 |
| 二重数组/字符串变量的下标形式 | `ABL:0:2`、`TALENT:(COUNT+1):2` 出错；字符串变量省略参数也可能出错 | 均可，字符串变量参数可省略 |
| CSV 中的异常数字 | `0xFF` 按 0 处理 | 报错并使该定义无效 |
| 不自然的写法 | `A:0:1:99999 +-RESULTS:0=@=+123|*?=Y` 也能工作 | 报错 |

### 其他行为差异

- **SIF 的下一行**：Eramaker 把空行/注释行也当作 SIF 的目标（`SIF 条件 → ;注释 → PRINT` 时 PRINT 总是执行），且允许下一行是 `IF`/`REPEAT`。Emuera 把空行和注释视为不存在，且限制 SIF 的下一行类型（不可为标签、空行/注释、IF、REPEAT 等）。
- **省略参数**：Eramaker 中省略 `IF`/`ELSEIF`/赋值参数行为未定义（省略 `RETURN` 参数相当于 `RETURN 0`）；Emuera 一律按 0 处理并给警告。
- **函数名字符**：Eramaker 允许任意符号与双字节字符；Emuera 允许双字节字符但符号只允许 `_`，且不建议以半角数字开头（数字开头无法作为表达式内函数调用）。ver 1.721 起函数名含符号降为「警告 Lv1」而非立即报错。
- **RAND**：Eramaker `RAND:X` 在 X=0 时返回 0，否则返回（0～32767 随机数）% |X|——X 为负也能用、结果不超过 32767、X>1000 时偏差明显。Emuera 返回（0～18446744073709551615 随机数）% X，X≤0 报错，X 有效范围 1～9223372036854775807。
- **WAIT**：Eramaker 执行 WAIT 时不换行、按 Enter 时换行；Emuera 光标在行中间时执行 WAIT 即换行，按 Enter/点击不换行。
- **JUMP**：Eramaker 不能从 CALL 调用的函数里 JUMP 出去；Emuera 可以，且在 JUMP 目标中 RETURN 等价于在来源函数中 RETURN。
- **CALLNAME**：Eramaker 在 CALLNAME 为空字符串时返回 NAME；Emuera 返回空字符串。可用选项「CALLNAME 为空字符串时使用 NAME」弥补（源码 `ConfigCode.CompatiCALLNAME`，`Runtime/Config/ConfigCode.cs:96`），但不能完全重现（如 Eramaker 添加角色后 Emuera 读档）。
- **FORM 展开**：Eramaker 反复展开直到无可展开（自引用/循环引用会冻结）；Emuera 只展开一次。
- **EVENT 函数属性**：Eramaker 按 #PRI 组 / 普通组 / #LATER 组分别遍历调用，#PRI+#LATER 并存会被调用两次，#SINGLE 仅在返回值为 1 时中断且对每组分别生效。Emuera ver 1.800（开发版 1.756alpha018）起完全重现；此前是整体排序后一次遍历，#PRI+#LATER 并存视为都没有，#SINGLE 中断即全部结束。另 1.751b 之前 #SINGLE 在返回值非 0 时即中断，1.752 修正为仅返回值 1。
- **gamebase.csv 的「代码」**：超出 32 位范围的值，Eramaker 转十六进制取低 8 位；Emuera ver1.803 及以前变为 0，1.804 起按所写数值原样（`GAMEBASE_GAMECODE` 亦改为 64 位范围），1.805 起存档游戏代码为 0 时任何本体都能读取。
- **abl.csv 等的索引**：Eramaker 允许 `99999:技巧` 这类越界定义（但 PRINT_ABL 时会出错）；Emuera 直接忽略越界行，需要更大范围用 `VariableSize.csv`。
- **train.csv**：Eramaker 中 `XXX,99999` 配 `@COM99999` 可执行、负值定义命令可见但无效；Emuera 可定义范围到 `VariableSize.csv` 的 TRAINNAME 大小为止（默认 0～999），越界忽略。
- **CharaXX.csv**：`基础,0`（省略第三值）Eramaker 按 0 处理、`素质,0,100`（多出的值）忽略并变为 1；Emuera 中前者 MAXBASE:0=1、后者 TALENT:0=100。角色「编号」小于 0 或 ≥1000 两者行为相同。
- **换行符**：Eramaker 只有 CR 时不视为换行并引发故障；Emuera 把 CR 也视为换行。

### 未修复的 Bug（Emuera 也重现）

- **文件读取顺序取决于文件系统**：CALL 多重定义函数时调用哪个取决于文件读取顺序；公开脚本多假定 NTFS，FAT 上不正常。
- **REPEAT-REND 结束时 COUNT 会 +1**（BREAK 退出时也是）；FOR-NEXT 的循环变量同样 +1——与一般语言的 for/break 语义不同。
- **NEXTCOM**：初始值 -1，但执行后赋的是 0 而非 -1，会不断重复 COM0；官方说明未提及该变量。Emuera 为兼容而复制，建议改用 DOTRAIN/CALLTRAIN。

### 变更的特性：SP 角色

Eramaker 中 CSV 里 `CFLAG:0` 非 0 的角色是 SP 角色，只能 `ADDSPCHARA` 注册（也是 bug 来源）。Emuera ver 1.816 起默认不再支持：`CFLAG:0` 不再特殊，所有角色都可用 `ADDCHARA`。兼容性选项「SPキャラを使用する」可还原旧行为（源码 `ConfigCode.CompatiSPChara`，`Runtime/Config/ConfigCode.cs:117`、`Runtime/Config/Config.cs:113、521`），除运行旧脚本外不建议使用。

## 兼容性开关（ecd/Compatibility.md 要点）

兼容性矩阵共 60 项，标记含义：✓ 支持、✗ 不支持、△ 行为不同。要点：

- **Eramaker 也有、Emuera 沿用**：`@函数`、`;` 注释、`$标签`+GOTO、A~Z/DAY/MONEY 等系统变量、IF/REPEAT/BREAK/CONTINUE、CALL/RETURN、ARG/ARGS/RESULT、#PRI/#LATER/#SINGLE/#ONLY、GLOBAL(S)、标准 CSV 与存档界面。
- **Emuera 新增**（Eramaker ✗）：行连接 `{ }`、`#DIM/#DIMS`、私有变量、引用型变量（1.810 起）、`CONST`、ERH 广域变量、`CDFLAG`、FOR/NEXT、WHILE/DO、SELECTCASE、TRYC 系、TRYCALLLIST、参数初始值与按引用传递、#FUNCTION(S)、#DEFINE 与 ERH、PRINTBUTTON/PRINTDATA、TINPUT 系、HTML_PRINT、图片/精灵/动画、SAVEDATA/LOADDATA/CHKDATA、SAVEGLOBAL、UTF-8/二进制存档、`_replace.csv`、`_rename.csv`（来自 EraMakerEx，默认关闭）。
- **行为不同（△）**：数组越界（Eramaker 静默忽略 vs Emuera 报错）、数组末元素、RAND、单目 `-`、字符串比较/拼接/三元、DRAWLINE 换行规格（1.739 前后不同）、函数名符号、事件函数可被 CALL（Emuera 默认禁止，开关恢复）、CSV 异常数字、CALLNAME 为空、SP 角色。

△ 项常用开关（源码均有对应 `ConfigCode`，`Runtime/Config/ConfigCode.cs:95-117`）：

| 现象 | 开关 |
|---|---|
| RAND 取值范围/偏差 | `CompatiRAND`（擬似変数RANDの仕様をeramakerに合わせる） |
| 1.739 后换行错乱 | `CompatiLinefeedAs1739`（ver1739以前の非ボタン折り返しを再現する） |
| 函数参数「类型不符」 | `CompatiFuncArgAutoConvert`（ユーザー関数の引数に自動的にTOSTRを補完する） |
| 使用 SP 角色 | `CompatiSPChara`（SPキャラを使用する） |
| 事件函数被 CALL | `CompatiCallEvent` |
| CALLNAME 为空 | `CompatiCALLNAME` |
| DRAWLINE 行为 | `CompatiDRAWLINE` |
| 参数省略规则 | `CompatiFuncArgOptional` |

改造版（私家版、EM+EE 等）以 Emuera 为基座，通常额外提供更多图像/精灵/动画指令、TOOLTIP_*、更多内置函数与变量——脚本用到时应确认目标引擎是否具备。

## 术语表（ecd/Terminology.md + ecd/Glossary.md）

Terminology.md 提供 85 条中/英/日对照，Glossary.md（OSDN EmuDic 翻译）给出定义，此处合并收录核心条目：

**模式与界面**：普通模式（双击 exe 启动）/ 解析模式 Analysis Mode・解析モード（拖文件启动做语法检查，1738g 起可显示加载报告；需配好所用改造版的 CSV 才能检查元素字符串类型）/ 调试模式（`-debug` 启动）。主窗口・メインウィンドウ；主控制台・メインコンソール；调试窗口／调试控制台；设置对话框；剪贴板对话框（Ctrl+C）。

**代码单位**：

- 命令 Command・命令：如 PRINT、WAIT。注意与函数区分。
- 函数 Function・関数：`@名称` 定义、CALL 调用。
- 事件函数 Event Function・イベント関数：名称以 EVENT 开头、由系统调用；定义多个则都被调用。
- 表达式内函数（=「可在表达式中使用的函数」之简称）：可在表达式中直接调用；与匿名函数/内联函数无关。
- 内置函数 Built-in Function：引擎自带、无需 `@` 定义的表达式内函数，如 ABS(X)、GETTIME()——可理解为「可用于表达式中的指令」。
- #FUNCTION(S) 函数：既是函数又是表达式内函数。
- 预处理指令：以 `#` 开头的行（属性如 #PRI/#FUNCTION，定义如 #DIM/#DEFINE/#LOCALSIZE）或 `[]` 括起的特殊区块。
- 行 = 物理行；语句 = 处理单位（一行一句铁则下行≈语句）；表达式 = 变量/常数/表达式内函数/非赋值运算符/括号的组合，赋值运算符不能出现在表达式中；数式/文字列式 = 结果为数值/字符串的表达式；FORM = 格式化字符串。

**变量**：

- 伪变量：RAND、CHARANUM 等按变量形式书写但实为运算的东西（内部近似表达式内函数）。
- 数组变量（FLAG、STR 等，元素数由 VariableSize.csv 修改）；角色变量（元素随 ADDCHARA/DELCHARA 增减）；双重数组变量（既是角色变量又是数组变量，如 CFLAG:TARGET:2）；多维数组变量（DA/TA，参数不可省略）；角色多维数组变量（截至 ver1807 仅 CDFLAG，三个参数不可省略）。
- 局部变量：LOCAL/LOCALS 及私有变量按函数分别准备；注意 LOCAL/LOCALS 实际是名为 `LOCAL@函数名` 的 public static 变量，函数外可引用/赋值、递归时共享。
- 广域变量：所有函数间共享（≈一般语言的「全局」）；ERH 中 #DIM 可定义。
- 全局变量：跨存档共享（SAVEGLOBAL 系），与一般语言的「全局变量」无关。
- 私有变量：`#DIM`/`#DIMS` 按函数定义，函数外不可用 `@函数名` 方式访问。
- 引用型变量：`REF`（1.810 起按引用传参；1.815 起 REF 指令本身不可用）。

**CSV 字段对照**（日文原文 → 变量）：`番号`→NO、`名前`→NAME、`呼び名`→CALLNAME、`あだ名`→NICKNAME、`基礎`→BASE/MAXBASE、`能力`→ABL、`素質`→TALENT、`経験`→EXP、`刻印`→MARK、`相性`→RELATION、`フラグ`→CFLAG、`助手`→ISASSI、`アイテム`→ITEM、`調教コマンド`→TRAINNAME。

**显示相关**：对齐（LEFT/CENTER/RIGHT）、绘制接口（WINAPI/GRAPHICS/TEXTRENDERER）、按钮（`[0]` 形式）、精灵、资源（resources/）、警告等级（0～3）、兼容性开关（互換性オプション）、无限循环（超时限且无 WAIT 时警告）。

## 与源码的差异/备注

1. **兼容性开关在源码中全部可证**：`Runtime/Config/ConfigCode.cs:95-117` 定义 `CompatiErrorLine/CompatiCALLNAME/CompatiRAND/CompatiDRAWLINE/CompatiLinefeedAs1739/CompatiFuncArgAutoConvert/CompatiFuncArgOptional/CompatiCallEvent/CompatiSPChara` 等，`Runtime/Config/Config.cs:104、113` 处加载。文档与源码一致。
2. **TERMINOLOGY/Glossary 与源码对应**：「LOCAL 实为 LOCAL@函数名」对应 `Runtime/Script/Data/IdentifierDictionary.cs` 中对 `コード中でローカル変数を@付きで呼ぶことは推奨されません` 的警告（见 ecd/Error_Index.md 条目）；Glossary 的定义在源码无独立对应物，属概念层说明，无不一致。
3. **Version_Index.md 只是「文档正文出现过的版本信息」汇总**，非完整更新履历（页面自述 history 未收录）；引用其中条目时宜回溯到对应章节。ecd 标注 1.756alpha018 与 1.800 两条为同一事件的开发版/正式版分界。
4. **两套文档差异**：zh 目录**没有** Compatibility.md、Version_Index.md、Terminology.md——这三页是 ecd（Era 中文文档）的原创速查页，未进入旧版抓取集。zh/Difference.md 与 zh/Glossary.md 的正文与 ecd 一致（同一翻译的不同抓取版式：zh 版标题层级不同、示例代码行号标注独立，内容无实质出入）。
5. Difference.md 中「#SINGLE 修正于 1.752」与 Compatibility.md 中「#SINGLE 的中断条件在 1.752 修正」一致，源码 `Runtime/Script/Process.CalledFunction.cs` 的事件函数调用顺序未逐行核对，此节按文档收录。
